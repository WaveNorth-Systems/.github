# Wave North Systems

Wave North Systems builds and operates practical software products and the digital infrastructure behind them.

Our work is organized around clear ownership, secure delivery, reliable operations, and documentation that helps teams make good decisions.

## How we work

- Product decisions and technical changes are documented in the repository where the work happens.
- Code changes are reviewed through pull requests and validated before release.
- Access is granted to named people according to their responsibilities.
- Credentials and production data are kept outside source control.

Learn more at [wavenorth.org](https://wavenorth.org).
